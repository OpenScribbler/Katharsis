## The passes a reply actually goes through

I build a reply in four passes: choose what goes in (Rules 1–2), decide what I am allowed to claim (Rule 3), shape the message opening-body-closing (Rules 4–6), then write the sentences (Rules 7–11). The file runs in exactly that sequence, and nothing in it tells a reader the numbers are a sequence rather than an index.

## Two rules sitting in the wrong pass

Rule 5's second paragraph — "a code marks something I have to act on... cut everything else instead of coding it" — is a Rule 1 decision under a Rule 5 heading. It fires one pass too late: by the time I reach it in file order I have drafted the groups, and the paragraph's remedy is to restructure the message I just built.

Rule 3's opening sentence and Rule 8 are one requirement stated twice, 103 lines apart: "say what settled the claim, in the sentence that makes the claim" against "evidence... belongs in the same sentence as the claim." Rule 3's third paragraph, on stacked qualifiers, is a sentence rule stranded 110 lines from the other sentence rules.

## What rearranging would cost

Rule 5 forward-references Rules 4, 6, and 8; Rule 6 references nothing. Cross-references are all by number, so any rearrangement is a sweep of the whole file with a silent failure mode — a stale "Rule 8" still reads as a valid pointer to the wrong rule. This session already paid that cost once, when the paragraphs I wrote under Rule 9 became Rule 5.

## Questions

❓ **Q1** - **Does Rule 5's coding-threshold paragraph move up to Rule 1?** — the paragraph deciding what earns a code, distinct from the mechanics of how a coded item is formatted.
   a. move it into Rule 1 as its own paragraph, so the include/exclude decision lands in one pass
   b. leave it in Rule 5, keeping everything about codes in one place to look up
   c. split Rule 5 into two rules — what gets coded, and how coded groups are formatted

➡️ a — Rule 1 is where I decide what survives, and c costs a renumber of six rules for a gain a heading already gives.

❓ **Q2** - **What happens to the overlap between Rule 3 and Rule 8?**
   a. cut the duplicate sentence from Rule 3, leaving it about checking before writing, and let Rule 8 own placement
   b. cut Rule 8 and let Rule 3 own both
   c. leave both, on the grounds that repetition in a rules file is cheap

➡️ a — Rule 3 is about when you are allowed to write the claim, Rule 8 about where the evidence goes, and a is the split that keeps each rule to one job.

❓ **Q3** - **Do cross-references switch from number to rule name?** — "under Rule 4" becoming "under *Put the finding on its own line, first*".
   a. switch to names, so rearranging never breaks a pointer
   b. keep numbers, which are shorter and match how you refer to rules in conversation
   c. use both, as "Rule 4 (*Put the finding first*)"

➡️ c — it survives renumbering and keeps the short form you actually say out loud, at the cost of a few words per reference.
