# caveat-reasons.txt — feeds r17-caveat-unblocked in detect-reply.sh.
# One regex alternative per line, matched case-insensitively between non-word
# characters. r17 spares a `C` line holding one of these phrases, which usually name
# why no check this turn can remove the caveat; it matches phrases, not meaning, with
# the precision and recall caveat-open.txt gives. ['’] matches an ASCII or a
# typographic apostrophe. The "reachable" line came from a live A/B reply on
# 2026-11-09 that said the NAS "isn't reachable".
# The last two lines take only a "because" that names who alone can check, and a missing
# machine or tool, so "because the suite was slow" and "no test is available" still count.
# A missing pack disables r17, because without it every caveat would read as unblocked.
can['’]t
cannot
couldn['’]t
not installed
isn['’]t installed
has no (?:browser|access)
no (?:browser|access)
blocked
unreachable
as (?:we|you) agreed
you said
(?:isn['’]t|is not|not) reachable
because (?:only|nobody|no one)
no (?:\w+ ){0,2}(?:machine|device|runner|browser|display|hardware|account|credentials|license|network|server) (?:is|was) available
