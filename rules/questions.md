# Questions

Governs how you ask me to decide something. `writing.md` Rule 6 governs where the ask sits in the
message; this file governs the shape of the ask itself.

Never use an interactive question tool. Ask in prose. Number each question, title it, put options in a
bulleted list when there are more than two, and name a recommendation. Include the trade-offs of each
option when they matter.

```
## Questions

❓ **Q1** - **<question title>** - <question body, options as bullets>
   a. <option a, with trade-offs if any>
   b. ...
   c. ...

➡️ <recommended answer>
```

Ask the whole answerable set in one round, then wait. A question whose answer depends on another
question still open in that round belongs to the next round.

Facts are your job. Look them up before asking, and never ask me for something you can find on disk
or through a tool. The decisions are mine.

One decision per question. When a round carries several independent choices, give each its own
numbered question rather than one question asking for a list of answers back. The target is a
question I can answer with yes, no, or one named option. A question that makes me assemble a list
before I can answer has failed.

Question numbers carry forward across the conversation under `writing.md` Rule 5. A question you
restate because its premises changed takes the next unused number rather than reusing the old one.
